# СочиГУ — «Единое окно»

Вёрстка раздела «Единое окно в образовательных организациях» Сочинского государственного университета по макетам Figma, с адаптацией под мобильные устройства.

- Отчёт о работе: [REPORT.md](REPORT.md)
- Предложение по анимации: [ANIMATION.md](ANIMATION.md)

## Как открыть

Сборка и зависимости не нужны: это статичные HTML, CSS и JS.

1. Откройте `index.html` в браузере двойным кликом.
2. Либо запустите локальный сервер из корня репозитория:

   ```bash
   npx --yes serve .
   ```

   и откройте `http://localhost:3000`.

Мобильная версия: DevTools → Toggle device toolbar (Ctrl+Shift+M) → ширина 375px.

## Адаптив

| Ширина | Поведение |
|--------|-----------|
| 1440px и шире | 1:1 с макетом, контент центрирован в колонке 1440px |
| 1281–1439px | Та же сетка, отступы и зазоры масштабируются через `min(px, vw)` |
| 1025–1280px | Сложные композиции (кредит, права, стоимость) ужимаются |
| 769–1024px | Планшет: 2–3 колонки, маскоты переходят в поток |
| до 768px | Мобильная версия: одна колонка, таблицы превращаются в карточки, таймлайн становится вертикальным списком |
| до 420px | Футер в одну колонку, уменьшенный заголовок |

## Шрифты

В макетах основной шрифт SF Pro, а в таблицах стипендий гротеск, близкий к Onest.
На устройствах Apple используется системный SF Pro. На остальных подставляется **Inter** (Google Fonts) с трекингом −0.02em, чтобы переносы строк совпадали с макетом. Для таблиц стипендий подключён **Onest**.

## Проверено

Chrome / Edge (Windows), ширины 375, 768, 1024, 1440, 1920px.
